## 铁律速查
1. **updatedAt 必刷 + 写完即推送**：bump 时间戳 → `json.load` 通过 → **立即** commit/push，早于早报/记忆/单链。诚实性靠 note 如实写复核结论，**绝不伪造赛果**。
2. **JSON 硬校验**只依赖 `json.load` 是否抛错；复杂转义别塞 `python -c`+单引号 → 写临时 .py 再 `rm`。
3. **先拉后采/先拉后推**：读或 push 前 `git fetch origin && git rebase origin/main`，禁止强推；**每轮开头先 `git status --short`**。

## 单链滚动刷新（once 链）
- 全局仅 1 个 name 含「刷新」的 **once**（recurring 主任务名也含「刷新」，不算）。命名 `刷新链-[YYYYMMDD]-[HHMM]`，`cwds` = `C:/Users/pengz/Documents/GitHub/pingpong-schedule`。**创建 once 不要传 `rrule`**。
- 时刻：赛前 T=K-1h（仅 T∈(now,now+30h]）；赛中整链只加 1 个 now+30min 点；升序后 30 分钟聚类（≤30min 并入取最晚）；取 ≥now+30min 最早簇为 T_next；无候选则暂歇。**凌晨场（00:00-07:59）真实开赛是次日，K 须修正**。
- 对齐时**先 list 再删旧建新**；**T_next 与现存 once 一致 → 保持不动**。

## 数据约定
- days 四日期：昨日（带 result，**原样保留**）+ 今日 + 明日 + 后日。risk 仅未结束场填（🔴/⚠️/✅ + 括号大白话标签 + 口语原因，台号写 `央视5`/`央视5+`，2~3 句）；**已填 result 必须移除 risk**。
- **`result` 用取胜者视角**：赢家写在前（即使赢家是 playerAway），如 `梅谢芙 3-1 王艺迪(11-7/…)`。
- **空窗天**整段说明写入 day 顶层 `dayNote` 纯字符串，`schedule` 置空 `[]`；**有真实直播的日子不要写 dayNote**（else-if，写了＝死内容）。要点每条 ≤100 字、每天 ≥8 条、括号成对；末尾「下一站…」句内**禁句号**。名单句口诀：**「名单句在前、`背景:` 断后」**。
- **【每日收录口径】** 有真实直播的日子**每天固定收录 4 场 = 国乒场次 + 日本焦点**，其余改在**当日早报正文**列全。
- **`schedule` 是死内容的条件**：只在 **matches 为空的 else 分支**渲染（app.js:1975-2008）→ 有 matches 的日子加 schedule 不显示，只能 note 留痕。
- **`nextEvent.note` 追加文本禁用 `→`**（触发时间线分支），脚本加 `assert`。**新段落必须插在首句第一个 `。` 之后**（首句第一个括号是 `parseEventMeta` 的 title 锚点；prepend 会让位次表丢锚点、`emeta__rank-item` 从 12 退化到 4）。
- video.json 顶层仅 `days[]`，用 `platform`（非 channel）；`renderVideoBlock` **不渲染 result** → 赛果写进 `note` 首句。团体赛按 5.3.1。

## 前端判据（子上定）
- **【铁律】`risk` 文案禁写「电视看不到」类词**（9/10 新踩坑）：`riskSaysNoTV` 正则命中 `手机|APP|app|客户端|咪咕|央视频|不直播|电视上不播|电视不播|只在.*播|只在.*看` → `isTVMatch` 判 false → **整场比赛从页面彻底消失**（比不写还糟）。**对策：risk 里只写「电视看不全/离切播只剩 N 分钟」，把「想看全用央视频/咪咕」移到早报与 note。**写完必跑渲染自检确认该场关键词命中。
- **倒数日铁律**：赛事已开打（`ne.date ≤ today`）→「距今天 X 天」徽章**不显示**，用真实日期判定，不依赖 daysAway。⚠️ `tag--soon` 也是「明天/后天」标签默认 class（app.js:1864），自检要看 `day--next` 是否为 0。
- **下一站模块窗口铁律**：仅在「今天/明天/后天都没有赛事安排」时出现（`isNextEventWithinWindow(ne, today, 2)`）。窗口内有赛事时 `day--next`=0，`emeta__rank-item`/`next__lines` 随之归零，**属正常**。
- 昨日若 `matches` 为空 → 该日整段（含 dayNote 与 video 块）都不可见。视频块只在「当日无央视电视直播」分支渲染 → 有央视的日子不必写 video.json（仍须按八·乙在 note 留痕）。
