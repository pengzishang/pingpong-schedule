# 项目记忆: pingpong-schedule 央视乒乓赛程

> 完整任务指令在项目根 `采集说明.md`（唯一指令源）。本文件只记**踩坑与判据**，不重复指令书内容。

## 铁律速查
1. **updatedAt 必刷**：每次任务（主任务 8h / 刷新链 once）跑完，无论有无数据变更，都必须 bump `updatedAt` + git push。用户原话「无变更也要显示时间变了，要不然我怎么知道你是不是干了活」。诚实性靠 note 如实写「本轮复核未发现数据变更」，**绝不伪造赛果**。
2. **写完即推送**：data.json 写完 + json.load 校验通过 → 立刻 `git add/commit/push`，早于早报/记忆/单链对齐（2026-08-23 06:44 事故：推送排末尾被打断，网页时间不变）。
3. **JSON 硬校验**：`Edit` 的 `\n` 有被落盘成真实换行的风险 → note 混入真实换行即非法 JSON，前端 `res.json()` 抛错、网页停旧数据。改完必跑 `python -c "import json;json.load(open('data.json',encoding='utf-8'))"`。复杂转义别塞 `python -c`+单引号，写临时 .py 再删。
4. **先拉后采/先拉后推**：任何读取或 push 前 `git fetch origin && git rebase origin/main`。禁止强推。

## 单链滚动刷新（once 链）
- 全局同时仅 1 个 name 含「刷新」的 once；建新前先删旧。命名 `刷新链-[YYYYMMDD]-[HHMM]`，`modelId` 必须 `hy3`，`cwds` 用 Windows 绝对路径 `C:/Users/pengz/Documents/GitHub/pingpong-schedule`（无前导斜杠会被误拼到 Program Files）。
- 刷新时刻计算：赛前 T=K-1h（仅 T∈(now,now+30h]）；赛中整链只加 1 个 now+30min 点；候选升序后 30 分钟聚类（≤30min 并入取最晚）；取 ≥now+30min 最早簇为 T_next；无候选则链暂歇等主任务。
- **凌晨场日期修正**：data.json 按「08:00~次日08:00」归类，00:00-07:59 的场写在「今日」date 下但真实开赛是**次日**；K 计算须修正，否则这批场全部漏算、链假暂歇。
- 赛中区间 = 当前 ∈ [K-30min, K+3h]（含开赛前 30 分钟，保证 23:35 那跳能覆盖 00:00 的场）。
- `live` 字段：已开赛且 result 为空时写进行中局分，格式同 result；result 一出即清 live。前端 60s 轮询。

## git
- 只推 origin（github.com/pengzishang/pingpong-schedule）；gitee 已弃用。
- 提交信息：`赛程刷新_YYYY-MM-DD_HH:MM`（刷新）/ `每日赛程更新 YYYY-MM-DD`（主任务）。
- push 被拒（non-fast-forward，前端机抢先）：`git stash` 无关 → `fetch` → `reset --hard origin/main` → `checkout <本地已校验 commit> -- data.json` → commit → push。**勿强推**。

## 数据约定
- days 四日期：昨日（带 result 战报，原样保留）+ 今日 + 明日 + 后日。subtitle 固定「央视直播 · 乒乓球赛程 · 每日更新(可筛选 全部/国乒/日韩)」。
- risk 仅未结束场填：🔴/⚠️/✅ 开头 + 括号大白话标签 + 口语原因建议，⚠️另起一句证据可靠性，📊另起一句人头对战，整段 2~3 句。已结束省略 risk。
- 「下一站…」句内**禁句号**（前端靠首个句号截断），句内用逗号分隔出战/缺席名单。
- video.json 顶层仅 `days[]`，用 `platform`（非 channel）。`renderVideoBlock` **不渲染 result** → 赛果必须写进 `note` 首句。团体赛按 5.3.1：playerHome/Away 填队名，关键球员进 Info，nationHome 填中国以进「国乒」标签页。

## 真伪判定（避免误杀 & 避免被骗）
- **AI 幻觉赛果**：k.sina.com.cn 大量「本文由AI生成」稿把赛前预测写为既成赛果。采信前做可行性校验：K + 局数×8min ≤ 当前，否则排除。
- **旧闻翻新**：「XX 怎么看回放/直播」体裁服务性短文常把旧赛事当当日热点（8/30 sina.cn 稿把 7/18 全锦赛混双当热点）。鉴别：拿赛事名+对阵反搜原始通稿核对发布日期。
- **跨赛事旧战报**：同一对阵相邻两站重复，旧站战报霸屏（蒯曼4-1早田实为 8/08 横滨）。鉴别：核对「下一轮对手」是否与本站签表一致。
- **单一平台多稿矛盾 ≠ 事件为假**（邓亚萍杯教训）。分层判据：①事件要素多平台一致 → 为真；②仅直播渠道未官宣 → 只影响是否写入文件；③个别夸张细节无出处 → 只剔该细节。处置：不写入但必须在 note + 早报留痕，注明「赛事为真、央视不转播」。
- **条件场作废**：上轮「若 A 胜则某日某时」的条件场，本轮必查条件是否成立；A 出局则删条件句并补一句明确否定（如「今晚 21:00 没有樊振东」），不能静默删。
- 权威源优先级：@WTT世界乒联 微博（uid 7556183438）逐局赛果 = 官方口径，单源可写 result；虎扑/直播吧/腾讯新闻正文次之。该号与 @咪咕体育 终局后 5~15 分钟发稿 → 开赛超 1 小时仍未发 = 仍在进行，别套旧比分。
- 抓进行中局分：WebSearch 找实时图文直播稿（如「刘姚尧的文字城堡」）→ WebFetch 取最新一局。
- WTT 冠军赛男女单各 32 人正赛、**不设资格赛**；「需从资格赛打起」一律判错，正确是「从非种子位置打起」。
