## 铁律速查
1. **updatedAt 必刷 + 写完即推送**：bump → `json.load` 通过 → **立即** commit/push，早于早报/记忆/单链。**绝不伪造赛果**，未结束的 `result` 一律留空。
2. **JSON 硬校验**只依赖 `json.load` 是否抛错；复杂转义别塞 `python -c`+单引号 → 写临时 .py 再 `rm`。
3. **先拉后采 / 先拉后推**：`git fetch origin && git rebase origin/main`；禁止强推；**每轮开头先 `git status --short`**。
4. **前端测试 `node --test tests/*.test.js`**（不能 `node --test tests/`），**0 fail 才推**。
5. **生成脚本幂等**：会 prepend note 的临时 .py 加 MARK 检查（`if MARK in note: sys.exit(1)`）。
6. **curl 校验**下载到**仓库内**再删（Git Bash `/tmp` Windows 版 Python 看不到），或用 PowerShell。

## 单链滚动刷新（once 链）
- 全局仅 1 个 name 含「刷新」的 **once**（recurring 主任务名也含「刷新」，不算）。命名 `刷新链-[YYYYMMDD]-[HHMM]`，`cwds`=`C:/Users/pengz/Documents/GitHub/pingpong-schedule`，**不传 rrule**，带 `modelId=hy3`。
- 时刻（9.2）：赛前 T=K-1h（仅 T∈(now,now+30h]）；赛中整链只加 1 个 now+30min 点；升序后 30 分钟聚类（≤30min 并入取最晚）；取 ≥now+30min 最早簇为 T_next；无候选则暂歇。**只有 `matches` 参与计算，`schedule` 不算**。凌晨场（00:00-07:59）真实开赛是次日，K 须修正。
- 对齐时**先 list 再删旧建新**；T_next 与现存 once 一致 → 保持不动。

## 数据约定
- days 四日期：昨日（带 result，**原样保留**）+ 今日 + 明日 + 后日。risk 仅未结束场填（🔴/⚠️/✅ + 括号大白话标签 + 口语原因，台号 `央视5`/`央视5+`，2~3 句）；**已填 result 必须移除 risk**。
- **`result` 用取胜者视角**：赢家写在前（即使赢家是 playerAway）。
- **空窗天**整段写入 day 顶层 `dayNote` 纯字符串、`schedule` 置 `[]`；**有真实直播的日子不要写 dayNote**（写了＝死内容）。末尾「下一站…」句内**禁句号**；口诀**「名单句在前、`背景:` 断后」**。
- **【每日收录口径】** 有真实直播的日子**每天固定 4 场 = 国乒 + 日本焦点**，其余在当日早报正文列全。
- **`schedule` 只在 `matches` 为空的 else 分支渲染**（app.js:1975-2008）→ 有 matches 的日子加 schedule 是死内容，只能 note 留痕。
- **`nextEvent.note` 追加文本禁用 `→`**；**新段落必须插在首句第一个 `。` 之后**（首句括号是 `parseEventMeta` 的 title 锚点；prepend 会让位次表丢锚点）。
- video.json 顶层仅 `days[]`，用 `platform`；`renderVideoBlock` **不渲染 result** → 赛果写进 `note`。团体赛按 5.3.1。

## 前端判据
- **【铁律】`risk` 禁写「电视看不到」类词**：`riskSaysNoTV` 命中 `手机|APP|app|客户端|咪咕|央视频|不直播|电视上不播|电视不播|只在.*播|只在.*看` → **整场从页面消失**。只写「电视看不全/离切播只剩 N 分钟」，「想看全用央视频/咪咕」移到早报与 note。
- 赛事已开打（`ne.date ≤ today`）→ 倒数日徽章不显示。⚠️ `tag--soon` 也是「明天/后天」标签默认 class（app.js:1864），自检要看 `day--next`。
- **下一站模块**仅「今/明/后三天都无赛事」时出现；窗口内有赛事时 `day--next`/`emeta__rank-item`/`next__lines` 归零**属正常**。
- 昨日 `matches` 为空 → 该日整段不可见。视频块只在「当日无央视直播」分支渲染。

## 自检两层必做
① 解析层 `api.parseDayNote`（括号配对、squad/absent 一致、要点不超长）。
② 渲染层 `buildAbove(api.prepareCtx(d,{now})) + buildBelow(ctx,d)`：`<section>` 正常值 **4**。
- `mergeVideo` 可能返回 undefined → `(r&&r.days)?r:data` 兜底；`parseNextEventNote` 必须传 `.note` 字符串。
- **进行中的测试禁写死淘汰/晋级名单或人数** → 只断言不变项，人数以 `computeSurvival` 动态比对。
- **「N 天后」假数据一律相对 `new Date()` 动态算**；判「今天」用本地日期拼接，**禁用 `toISOString().slice(0,10)`**。
- 修前端解析问题优先**在采集端改写法**，不动 app.js。

## 真伪判定
- **【铁律】结论与依据分开判定**：依据错只否定依据，结论另行求证。
- 「矛盾」先查是否描述不完整；**比分顺序先镜像校验**；**时刻取多数**，少数派留痕；量化数字打架只写定性。
- 条件场作废：上轮「若 A 胜则…」本轮必复查。权威源优先级：@WTT世界乒联微博 + WTT 官网 > 网易/搜狐/腾讯正文。终局后 5~15 分钟发稿 → 开赛超 1 小时仍未发＝仍在进行。
- **命中即判错**：把亚运写成「杭州亚运会」（实为日本爱知·名古屋）；澳门站名单出现温瑞博/向鹏或林诗栋；「537 万/2000 积分」＝大满贯口径；同稿内时差 ≠ 6 小时。
- 单源新事实不写 matches，改在 note 以「仅 N 源、待复核」披露。
- 主办方乒协稿只提当地台 ≠ 国内无版权；有直播但对阵未公布 → 不硬凑 playerHome/Away。
