## GitHub 推送踩坑
- GitHub `git push origin main` 偶发 `cannot lock ref 'refs/heads/main'` 瞬时竞态（远端 ref-lock 争用）：remote rejected 提示，但本回合 commit 实际已落地。修复：重试后 `git fetch origin`，比对 `git rev-parse HEAD` 与 `git rev-parse origin/main`，相等即推送成功，勿误判未推送而重推（重要）。
- git fetch/push 偶发 TLS EOF（error:0A000126 unexpected eof while reading），**push 仍可能已成功落地**；以 git rev-parse HEAD 比对 origin/main 相等即确认推送成功，勿因 stderr 报错误判未推送而重推（重要）。
- 「先拉后采」git rebase origin/main 遇工作树未暂存改动（如 .workbuddy/memory/* 未提交）会报 cannot rebase: unstaged changes 中止；**修复：rebase 前 git stash -u、之后 git stash pop 还原**（重要）。
