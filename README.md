# 🏓 国乒赛事日历(China Table Tennis Schedule)

> 央视直播的国乒乒乓球比赛时间表,**每天自动更新**,大字大按钮,长辈也能看清。

## 📺 在线访问

- 🌍 **主站(每日自动更新)**:**https://pengzishang.github.io/pingpong-schedule/**
- 🇨🇳 国内访问可能需要稳定的网络环境,GitHub Pages 在国内的可达性时好时坏,影响观看请见下方说明

## ✨ 功能特点

- **未来 3 天赛程**:每天滚动展示央视(CCTV-5 / CCTV-5+ / CCTV-16)转播的国乒比赛时间表
- **每日自动更新**:每 8 小时(0:00 / 8:00 / 16:00 左右)自动重新生成数据并推送
- **多源交叉认证**:每个场次时间经 ≥4 个独立来源验证,**同稿转载不算独立源**,数据可信
- **适老化设计**:18px+ 大字号、高对比黑白、大触控按钮(≥48px)、无装饰动效、手机竖屏友好
- **国旗标识**:每个选手旁显示所属国家/地区国旗(emoji),长辈一眼可辨
- **赛事标签**:每场比赛标注所属赛事(如 "WTT 横滨冠军赛")
- **插播风险标注**:与央视其他固定栏目(如《体育新闻》)重叠的场次,会明确标注并建议用央视频兜底
- **未公布场次**:有转播安排但对阵未公布时,展示央视转播时段卡片,不硬凑数据

## 📊 数据来源与认证规则

每个比赛场次的**具体时间**必须经过至少 4 个独立来源交叉认证;时间冲突时取**多数源时间(众数原则)**。

| 来源类型 | 代表 |
|---------|------|
| 央视官网 | sports.cctv.com |
| 独立节目单 | 电视猫 tvmao.com |
| 主流体育媒体 | 新浪体育、腾讯新闻、网易体育、搜狐体育、今日头条 |
| 视频平台 | 咪咕体育、PP 体育 |

> 同一篇报道被多家转载只计 1 个独立源,只有独立编辑/独立域名才算独立源。


## 🔄 数据自动更新流程

每天 0:00 / 8:00 / 16:00,自动化任务自动执行:

1. 从 ≥6 个独立来源采集赛程数据
2. 对每个比赛场次做多源交叉认证
3. 生成 Markdown 早报存档到本地
4. 生成/更新本仓库的 `data.json`,提交并推送到 GitHub
5. GitHub Pages 自动构建并部署,网页实时同步
